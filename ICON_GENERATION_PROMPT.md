# PROMPT DO BING IMAGE CREATOR - LootClicker Game Icons

## Główny Prompt (Skopiuj całość i wklej):

```
Create a pixel art game icon sheet with 4 icons in a 2x2 grid on white background. 
Each icon is 512x512px. Game style: retro 16-bit jungle theme.

Icon 1 (top-left): BANDAGES
- Medical gray/white bandages icon, 2-3 wrapped cloth strips
- Style: Thick white cross symbol (+) in center
- Colors: Gray (#888888), white (#ffffff), subtle shadows
- 16-bit pixel art with slight parchment texture

Icon 2 (top-right): VENOM BOTTLE
- Green poison/venom potion bottle
- Style: Glass bottle shape with cork top, glowing green liquid inside
- Colors: Dark green (#1a4d1a), bright green (#00ff00), brown cork (#8b4513)
- 16-bit pixel art, glowing effect on liquid
- Should look toxic and dangerous

Icon 3 (bottom-left): GOLD COIN
- Pixel art gold coin with ornate border
- Style: Circle coin with thick ornate frame, dollar sign $ in center
- Colors: Gold (#ffd700), darker gold (#daa520), brown ornate frame (#8b7355)
- 16-bit aesthetic with parchment background color (#f5deb3)
- Small pixel shine/highlights on coin

Icon 4 (bottom-right): RELIC SHARDS / GEMS
- Three mystical gemstones/crystal shards
- Style: Main large gem in center (purple/magenta), 2 smaller gems beside
- Colors: Bright magenta (#ff00ff), hot pink (#ff69b4), white highlights
- 16-bit pixel art with glowing effect
- Should look magical and valuable

Additional requirements:
- White background for all icons
- Consistent 16-bit pixel art aesthetic across all 4
- Jungle/adventure game theme
- Clear and readable at small UI sizes
- Each icon recognizable at 64x64 and 128x128 sizes
- Slight drop shadow for depth
```

---

## Instrukcje do użytkownika:

1. **Przejdź na:** https://www.bing.com/images/create
2. **Zaloguj się** na konto Microsoft
3. **Skopiuj cały prompt powyżej** (od "Create a pixel art..." do "...for depth")
4. **Wklej w Image Creator**
5. **Kliknij "Create"**
6. **Czekaj ~30 sekund** na wygenerowanie
