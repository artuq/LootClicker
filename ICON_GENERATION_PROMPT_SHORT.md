# PROMPTY DO BING IMAGE CREATOR - KRÓTKIE WERSJE

## OPCJA 1: Jeden prompt na całą planszę (REKOMENDOWANA)

```
4 pixel art game icons in 2x2 grid, white background: 
- Top-left: gray bandages with white cross symbol
- Top-right: green poison bottle with glowing liquid
- Bottom-left: gold coin with dollar sign, ornate frame
- Bottom-right: 3 purple/magenta glowing gem crystals
16-bit jungle game style, each icon 512x512px
```

Pixel art gold coin icon with ornate brown border and dollar sign in center,

Pixel art magic gem crystals icon, 3 purple/magenta glowing gemstones,
